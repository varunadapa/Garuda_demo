# Garuda — Futuristic Prototype

Quick prototype: simple Express API serving mock JSON and a single-page futuristic UI.

Requirements:
- Node.js (16+)

Run locally:

```bash
cd /home/bluecloud/Downloads/Garuda
npm install
npm start
# open http://localhost:4000
```

What you get:
- /api/crimes, /api/persons, /api/accuseds (mock data)
- Futuristic single-page UI at `/` with clickable items and detail view
